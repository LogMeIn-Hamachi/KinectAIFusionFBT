v1.0 Release · Windows x64 · NVIDIA

Your Kinect, in SteamVR.

Waist and foot tracking with Kinect v1/v2, Fast SAM 3D Body and depth. Everything is processed on your PC.

Extract the entire ZIP first.
Put it in a folder you can write to, keep the files together, and open KinectRGBD.exe. Models and native runtimes are already included.

Before you start

You need a powered Kinect, a supported NVIDIA GeForce RTX 4000 or 5000 series GPU (FP8 Tensor Cores required), SteamVR, a headset and two tracked controllers. Kinect v2 uses USB 3. Tested configuration: Windows 11, RTX 5070 Ti. Older RTX 20/30 series GPUs lack hardware FP8 and are not supported.

Install the official sensor software if needed: Kinect v2 runtime or SDK 2.0; Kinect v1 SDK 1.8. An existing working sensor installation is sufficient. No Python or CUDA developer toolkit is required.

One setup, at your pace

  1. Install trackers. Run SteamVR once, close it, then double-click Install SteamVR Trackers.cmd. Restart SteamVR and enable the Kinect add-on if asked.
  2. Find yourself. Open the app, press Start, choose your body and Lock player. First use takes longer while the GPU cache is prepared. Keep wrists and feet visible; your head can be out of view.
  3. Capture proportions. Set camera tilt first. Press Capture proportions, then stand naturally with feet apart. You get eight seconds to prepare and a four-second capture.
  4. Align to VR. Reset OVR space-drag/rotation offsets first. Follow each controller-pointing pose. Take as long as you need, then squeeze either trigger or click Capture pose. A three-second countdown lets you settle. Keep the same normal grip.
  5. Start tracking. Press Start trackers. Use Waist, Left Foot and Right Foot roles in SteamVR, then run VRChat's FBT calibration.
Next time
With the camera and room unchanged, reset OVR offsets, Start, Lock player and Confirm saved alignment. After that you can space-drag or turn the playspace; all three trackers should follow. Reset offsets again before confirming after an app restart. If SteamVR restarts during tracking, repeat Align to VR.

A simpler main screen

SAM optimized is selected by default. Model selection, SDK diagnostic comparisons, exposure and output options are under Advanced. Stop tracking before changing models. SAM original is included as an alternative.

Preview 23 fixes playspace conversion while retaining the existing model, smoothing and foot-contact behavior. Automated movement tests pass and the saved tracking replay is unchanged. Live OVR/VRChat behavior still needs confirmation. Single-camera occlusion, side-on and lying poses remain difficult.

Read the full guide, troubleshooting or release notes. These are plain text documents and can also be opened in Notepad.

To move the app, close it and SteamVR, run Remove SteamVR Trackers.cmd in the old folder, move the complete folder, then install the trackers again from the new location. Back up calibration and recordings before deleting an old installation.

Update the SteamVR driver

Close SteamVR, then run Update SteamVR Trackers.cmd in the new extracted package. Start SteamVR afterward. It switches registration to the bundled driver without deleting old files or settings. Keep the new folder in place.

The ZIP excludes personal calibration, preferences, recordings and cache. Recording is opt-in. Converted Meta/DINOv3 models and bundled libraries retain their terms: third-party notices and SAM agreement.
